# Design do Sistema - Análise Financeira Pessoal

## Arquitetura
O sistema é composto por:
- Banco de Dados: PostgreSQL (via Docker)
- ORM: SQLAlchemy
- Migrações: Alembic
- Processamento: Pandas
- Interface: Streamlit
